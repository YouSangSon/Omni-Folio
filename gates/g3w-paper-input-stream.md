# G3.8G2F Continuous local paper input — local acceptance passed

## Contract

- `paper-execute-stream` consumes stdin pipe NDJSON generated by Python `--watch --bundle`, using existing strict bundle decoding and the shared one-shot execution path. No broker/live/credential capability or dependency is added.
- One invocation arms only on its first fully validated step. Subsequent frames and idle heartbeats share its latest committed global/execution tokens. They are serialized, not competing database goroutines. Policy halt, ownership loss, expiry, malformed input or cancellation ends the run; no reacquire/rearm fallback exists.
- At most one copied frame waits at the unbuffered channel; scanner storage is bounded. Each record requires LF, with the complete record at most 4 MiB. Frames, read error and EOF retain order. Previous committed phases are not rolled back by a later transport error.
- CLI takes ownership of stdin. An inherited blocking pipe is duplicated, switched to nonblocking and wrapped as an `os.File`, with deadline support verified before use. Service closes and joins its reader on exit; CLI closes the original descriptor as well. Regular-file stdin and TTY are rejected. No stdout writes can delay renewal or producer disconnect.
- Python checks pipe ERR/HUP at every watch iteration, even with unchanged CSV. Non-pipe/StringIO outputs retain the prior behavior. Terminal failures use the existing redacted error path.

## Limits and sources

This is a local fixture stream, not durable transport, a supervised daemon, full source-snapshot capture, a broker connection, or an always-on throughput proof. Existing journal idempotency protects already committed decisions; the pipe itself has no acknowledgements. An individual long DB phase can exhaust the 30-second TTL. Append-only renewal replay cost remains unmeasured at sustained history sizes.

Focused official source check (2026-09-05): [os.NewFile](https://pkg.go.dev/os#NewFile) supports pollability for nonblocking Unix descriptors; [File.Close](https://pkg.go.dev/os#File.Close) cancels pending I/O on deadline-capable files. [ScanLines](https://pkg.go.dev/bufio#ScanLines) accepts an unterminated final line, so this protocol uses a strict LF splitter; [Scanner.Bytes](https://pkg.go.dev/bufio#Scanner.Bytes) may be overwritten by the next scan, so channel transfer copies the token. These are API contract sources, not executed process evidence.
