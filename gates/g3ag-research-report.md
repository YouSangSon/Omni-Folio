# G3.9 — stored research report

## Contract

`GET /v1/research/report` returns a closed `research-report.v1` observation and nullable report. Latest means registration sequence, including `no_promotion`, independent of selection and wall-clock order. Registry replay and artifact/registration capture share one transaction; projection uses those captured bytes after releasing SQLite's writer lock. Reads do not change the database, select a strategy, run an experiment or execute an order.

The reader supports the existing long-only SMA `1.0.0` artifact, canonical UTC timestamps, positive decimal research quantity, safe JSON integer windows/counts, and canonical metric strings up to 128 characters. It binds final-candidate parameters to the manifest and requires the duplicate fold lists to agree. Unsupported/corrupt latest data returns a generic 500 with no partial report or older fallback. Existing registration, recovery, database schema and backup acceptance remain unchanged; the public OpenAPI read contract is extended. Account/source IDs, artifact hashes, experiment names and trade traces are not exposed.

`metrics_verification=reported_not_recomputed` separates stored claims from a recomputation. Hash and field consistency do not certify reported returns. Walk-forward selects independently per fold: return is an arithmetic mean, drawdown the maximum and completed round trips a sum. The final candidate is selected on all pre-holdout data; only its final holdout uses the displayed windows. Buy-and-hold uses the same cash, quantity, costs and delayed-fill model on that holdout. No currency is inferred from the artifact. Fixed fees can make equity negative; losses and drawdown beyond 100% remain displayable.

Connections opens the report on demand. Loading, empty, initial error/retry and successful result states are distinct. Manual refresh is single-flight; failure preserves the whole previous response and original observation time. Percentages shift canonical decimal strings without binary floating-point or rounding. Long values wrap; fixed semantic labels describe promotion claims and evaluation scope.
